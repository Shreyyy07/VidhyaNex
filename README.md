# VidhyaNex

VidhyNex is a powerful and intuitive dashboard application designed to streamline school management activities. It provides a centralized platform for both students and teachers to monitor attendance, view timetables, and efficiently manage various academic activities.

<h2>Features</h2>
<h3>Student Dashboard</h3>

- View daily, weekly, or monthly attendance records.
- Access personalized timetables and schedules.
- Track academic progress and notifications.

<h3>Teacher Dashboard</h3>

- Manage student attendance records seamlessly.
- Create, update, and share class timetables.
- Post announcements and monitor student performance.

<h3>Admin Tools</h3>

- Assign roles and permissions for students and teachers.
- Generate detailed reports for attendance and academic activities.
- Oversee overall school management tasks.

<h2>Tech Stack</h2>
* Frontend: React.js, Tailwind CSS<br>
* Backend: [Node.js]<br>
* Database: [MySQL]

<h2>Usage</h2>
- Login or Register using credentials provided by the admin.<br>
- Navigate through the intuitive dashboard to access features like attendance tracking and timetable management.<br>
- Teachers and admins can manage records via dedicated portals.<br>
